# Fitness Zone

Sitio web educativo sobre actividad física y hábitos saludables, desarrollado con HTML, CSS y JavaScript.

## Archivos
- `index.html`: estructura y contenido.
- `style.css`: estilos, diseño responsive y animaciones.
- `script.js`: navegación, filtros, lista de hábitos y mini quiz.

## Cómo ejecutar
Abre `index.html` en un navegador. Se recomienda conexión a Internet para cargar Google Fonts y las fotografías de Unsplash.

## Publicar en GitHub Pages
1. Crea un repositorio público llamado `Fitness-Zone`.
2. Sube los cuatro archivos de este proyecto.
3. Abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
6. Espera a que GitHub Pages publique el sitio y abre el enlace que aparece en esa sección.

Proyecto educativo. La información es general y no sustituye la orientación de profesionales de salud o educación física.
